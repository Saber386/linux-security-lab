# Linux Security Lab

A practical Linux learning repository built during my cybersecurity journey.

This repository documents hands-on Linux administration, security concepts, networking fundamentals, log analysis, user management, permissions, SSH security, process monitoring, and system hardening techniques.

The goal is to develop a strong Linux foundation for Security Operations Center (SOC), Threat Detection, Incident Response, and Cybersecurity Engineering roles.

## Topics Covered

- Linux Fundamentals
- User & Group Management
- File Permissions & Ownership
- Process Management
- Networking Commands
- SSH Administration
- Log Analysis
- Bash Scripting
- Security Hardening
- SOC-Relevant Linux Operations

## Tools Used

- Ubuntu Linux
- Kali Linux
- Bash
- SSH
- Systemd
- Journalctl
- Netstat / SS
- Wireshark
- VirtualBox

## Learning Objective

To build practical Linux skills that are directly applicable to cybersecurity environments and enterprise security operations.
